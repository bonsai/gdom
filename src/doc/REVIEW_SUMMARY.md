## 🚀 使用方法

### 1. ファイルを配置
修正されたファイルをプロジェクトに上書きしてください。

### 2. Script Propertiesを設定
```
Google Apps Script エディタで:
ファイル > プロジェクト設定 > スクリプトプロパティ

追加:
- TEMPLATE_DOC_ID: テンプレートのドキュメントID
- OUTPUT_FOLDER_ID: 出力先フォルダのID
```

### 3. デプロイ
```bash
npm run push
# または
deno task push
```
